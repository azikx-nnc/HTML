Page 9 · Metadata

Describe the page
in the head

Metadata gives browsers and search engines useful information about the document.

Basic head

<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="My website">
  <title>My website</title>
</head>

charset

UTF-8 helps the page display text characters correctly.

viewport

The viewport meta tag helps a page work better on phones and tablets.

title

The title is shown in the browser tab.

<title>HTML Review</title>

description

A description tells search engines what the page is about.

<meta name="description" content="HTML review">
