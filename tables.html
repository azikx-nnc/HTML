Page 5 · Tables

Show data
in rows and columns

Use tables when the information naturally belongs in rows and columns.

Simple table

Name Age City
Ali 19 Tashkent
Sarah 20 London 
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Ali</td>
    <td>19</td>
  </tr>
</table>

Important tags

  • table - whole table
  • tr - table row
  • th - heading cell
  • td - normal cell

Remember

Use tables for data. Do not use tables to build the whole page layout.
