Page 8 · Semantic and layout tags

Give tags
a clear job

Semantic tags make the structure of a page easier to understand.

Simple page structure

<header>
  <nav>Menu</nav>
</header>

<main>
  <section>
    <h1>Hello</h1>
    <p>Text here</p>
  </section>
</main>

<footer>Footer text</footer>

Useful tags

  • header - top part
  • nav - navigation
  • main - main content
  • section - content section
  • article - independent content
  • footer - bottom part

CSS layout

CSS controls the position of these elements.

.page {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 20px;
}
