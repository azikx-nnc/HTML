Page 2 · Text formatting tags

Make text
easy to read

Use headings, paragraphs and simple formatting tags to organize text.

Basic text tags

These are some of the first tags beginners usually learn.

Headings

HTML has headings from h1 to h6.

<h1>My website</h1>
<h2>About me</h2>
<h3>My hobbies</h3>

Paragraphs

The p tag is used for normal text.

<p>Hello! This is my first HTML page.</p>
<p>I am learning HTML step by step.</p>

Simple formatting

Bold, italic and highlighted text are common examples.

<strong>Important</strong>
<em>Hello</em>
<mark>Look here</mark>

Other useful tags

You can also use br, small, del and ins.

Hello<br>
<small>Small text</small>
<del>Old text</del>
<ins>New text</ins>
